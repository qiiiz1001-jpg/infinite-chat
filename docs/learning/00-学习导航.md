## VS Code 阅读方式

打开桌面当前工程目录中的“轻聊项目学习.code-workspace”，或直接打开包含父 pom.xml 的 IM 根目录。打开讲义按 Ctrl+Shift+V；在预览中单击链接，在 Markdown 源码中 Ctrl+单击。工作区设置将源码在旁边打开，保留左讲义、右代码。链接相对于讲义自身解析，不要单独移动讲义。

第 03 篇按当前源码讲解接入、分发、会话授权与落库入口；第 05—07 篇再展开存储、群聊、AI 和红包细节。各篇仍按原文章节顺序阅读，不需要切换到旧版本源码。第 01 篇的鉴权入口已更新到 Common 公共配置。
