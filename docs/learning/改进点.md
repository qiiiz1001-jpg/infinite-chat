# 改进点

以下均为待完善项：

1. **消息确认与补拉**：客户端保存消息后回 ACK，记录可靠游标；重连后分页补拉、按消息 ID 去重，避免仅凭断线时间漏消息。
2. **无感续期**：补客户端自动调用刷新接口、保存新 Token、处理刷新失败；并发请求共用一次刷新。
3. **原子刷新**：校验旧 Refresh 与更新整对 Token 原子执行，避免并发刷新导致凭证错配。
4. **WebSocket 刷新衔接**：刷新后用新凭证重连，期间暂存未发送消息；补充关闭原因，后续可考虑绑定稳定登录会话。
5. **重试与退出**：补请求级幂等，防止重发产生重复消息；退出时主动关闭对应连接，减少等待心跳检测的延迟。
6. **推送失败恢复**：当前异步写出失败只记日志，消费进度仍可能提交，接收方可能漏显示；增加按接收方记录的失败补偿，结合客户端确认、可靠游标补拉与去重，避免只依赖断线时间。
